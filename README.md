# Email Extractor

![Email Extractor](images/icon128.png)

The Email Extractor is a Chrome extension that helps you quickly gather email addresses from web pages for marketing, outreach, research, and more.

## Features

- Collects email addresses from the current webpage (visible or all text).
- Real-time search and domain filter for results.
- Select/deselect emails for copy or export.
- Copy selected emails to clipboard.
- Save selected emails as TXT, CSV, or JSON.
- Dark mode toggle for the popup UI.
- Clear results with one click.
- Responsive and accessible popup design.

## Permissions

- `activeTab`: Needed to access and scan the content of the current tab.
- `downloads`: Needed to save extracted emails as files (TXT, CSV, JSON).

## Installation

1. Clone this repository or download it as a ZIP file and extract it.
2. Open Google Chrome.
3. Go to `chrome://extensions/` in your Chrome browser.
4. Enable "Developer mode" in the top right corner.
5. Click on "Load unpacked" and select the folder where you extracted the extension files.

## Usage

1. Click the extension icon in your Chrome toolbar to open the popup.
2. Use the options bar to:
   - Toggle between visible-only and all-text extraction.
   - Search/filter emails in real time.
   - Filter by domain (e.g., gmail.com).
   - Toggle dark mode.
3. Select emails to copy or export, or use the clear button to reset.
4. Use the action buttons to copy, save as TXT/CSV/JSON, or clear results.
